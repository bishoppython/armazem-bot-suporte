# Frete

Entrega local em Caruaru por motoboy: R$ 10,00.

Para outras cidades enviamos pelos Correios (PAC e SEDEX) ou por transportadora, com valor calculado pelo CEP no fechamento do pedido.

Frete grátis:
- Varejo: compras acima de R$ 299,00 para todo o Nordeste.
- Atacado: pedidos acima de R$ 1.500,00 para todo o Brasil.

Retirada na loja física é sempre gratuita.
